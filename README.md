## ✨ المميزات الرئيسية

- 🔒 **خصوصية مطلقة (100% Offline):** كافة معالجات الذكاء الاصطناعي وتوليد النصوص واسترجاع الملفات تتم بالكامل داخل جهازك عبر محرك `llama.cpp` عالي السرعة.
- ⚡ **المنبثقة السريعة العالمية (Quick Popup):** حدد أي نص في أي تطبيق بنظام ويندوز (متصفح، Word، PDF، كود، إلخ) واضغط الاختصار ليظهر لك رد فوري ذكي بجوار مؤشرك.
- 📌 **حفظ ذكي للموضع والمقاس:** اسحب نافذة المنبثقة لأي ركن على الشاشة أو غيّر أبعادها، وسيتذكر التطبيق موضعها ومقاسها المفضل تلقائياً.
- 📚 **استرجاع إثرائي RAG متعدد الصيغ:** اسحب وأفلت مستنداتك (`PDF`, `DOCX`, `TXT`, `Excel`, `PowerPoint`, `Code`) واسأل النموذج وسيجيبك مستشهداً بنصوصها الدقيقة.
- 🚀 **نسخة محمولة بالكامل (No Installation):** مدمجة بواجهاتها وأكوادها، وتعمل بدون الحاجة لتثبيت بايثون أو أي مكتبات برمجية.
- 🎮 **تسريع كروت الشاشة والمعالجات:** دعم مدمج لبطاقات **NVIDIA (CUDA)** ومعالجات **Intel/AMD (AVX)** لاختيار أعلى أداء تلقائياً.

### الخطوة 3: التشغيل
- انقر نقراً مزدوجاً على الملف:
  ```text
  run-mada-rag.bat
  ```
  أو شغل `mada-rag-server.exe` مباشرة.
- سيفتح المتصفح تلقائياً على واجهة المحادثة:
  `http://127.0.0.1:8787/chat`

> ⚠️ **ملاحظات هامة للمستخدمين عند أول تشغيل:**
> 1. **تنبيه Windows SmartScreen (الشاشة الزرقاء في ويندوز):**  
>    بما أن الملف التنفيذي جديد ومنشور كمشروع مفتوح المصدر (وليس موقعاً بشهادة رقمية تجارية مدفوعة من مايكروسوفت)، فقد يظهر لبعض المستخدمين عند أول تشغيل تنبيه ويندوز:  
>    `Windows protected your PC`  
>    - **الحل:** يكفي أن يضغط المستخدم على **More info (مزيد من المعلومات)** ثم **Run anyway (تشغيل على أي حال)** ليعمل التطبيق طبيعياً.
> 
> 2. **الانتظار لثوانٍ معدودة عند أول سؤال (Warm-up):**  
>    عند الضغط على اختصار التوليد لأول مرة أو إرسال أول رسالة، يحتاج محرك `llama.cpp` من 2 إلى 5 ثوانٍ لتحميل أوزان النموذج `.gguf` إلى الذاكرة (RAM / VRAM)، وبعدها تصبح كل الإجابات والاستجابات التالية فورية ولحظية وسريعة جداً.

## ⌨️ استخدام المنبثقة السريعة (Quick Popup)

تتيح لك المنبثقة السريعة ترجمة النصوص، تلخيصها، صياغتها، أو الإجابة على أي سؤال بضغطة زر دون مغادرة التطبيق الذي تعمل عليه:

| الاختصار الافتراضي | الوظيفة |
|---|---|
| **`Ctrl+Alt+Space`** | **الالتقاط والتوليد السريع:** حدد أي نص في أي برنامج ثم اضغط الاختصار لتوليد الرد فوراً |
| **`Ctrl+Alt+R`** | **إعادة فتح آخر رد:** يظهر نافذة التوست بآخر إجابة تم توليدها دون الحاجة لتحديد نص جديد |

### مميزات المنبثقة:
- **تحريك وسحب حر:** انقر على شريط العنوان واسحب النافذة لأي مكان تفضله على شاشتك.
- **تغيير الحجم:** اسحب حواف النافذة لتكبيرها أو تصغيرها حسب رغبتك.
- **تغيير الشفافية والثيم:** شريط مدمج لضبط شفافية النافذة وزر لتبديل الثيم الفاتح/الداكن.
- **أمر مخصص (Custom Prompt):** يمكنك تحديد أمر ثابت (مثل: *"ترجم ترجمة علمية"* أو *"لخص في 3 نقاط"*) من شاشة الإعدادات ليُطبق دائماً على النصوص المحددة.

## ⚙️ التخصيص والإعدادات

يمكنك الوصول لصفحة الإعدادات عبر النقر على أيقونة الترس ⚙️ في واجهة الويب أو زيارة `http://127.0.0.1:8787/chat`:

1. **مسجل الاختصارات التفاعلي:** اضغط على حقل الاختصار ثم اضغط المفاتيح التي تريدها على الكيبورد وسيقوم بتسجيلها وحفظها فورياً.
2. **موضع النافذة التلقائي:** يمكنك الاختيار بين (أسفل اليمين، أسفل الوسط، أسفل اليسار)، أو تحريكها يدوياً بحرية.
3. **اختيار النموذج يدويًا:** إذا كان النموذج في مسار آخر على جهازك، يمكنك النقر على زر استعراض لاختيار ملف الـ `.exe` وملف الـ `.gguf` عبر نافذة ملفات ويندوز.

## 🛠️ دليل المطورين (التشغيل من الكود المصدري)

إذا كنت ترغب في تشغيل المشروع وتطويره عبر بيئة بايثون:

### 1. المتطلبات:
- نظام ويندوز 10 أو 11 (64-bit)
- Python 3.10 أو أحدث

### 2. تثبيت المتطلبات:
```powershell
# استنساخ المستودع
git clone https://github.com/EngAlaaJahaf/mada-rag-assistant.git
cd mada-rag-assistant

# إنشاء وتفعيل البيئة الافتراضية
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# تثبيت الاعتماديات
pip install -r requirements-build.txt
```

### 3. تشغيل السيرفر محلياً:
```powershell
python server.py
# أو عبر السكربت المخصص:
.\تشغيل.bat
```

### 4. إعادة بناء الملف التنفيذي المدمج (Single Executable):
```powershell
python build_exe.py
```
*سيقوم السكربت بحزم السيرفر، وكيل الخلفية، ومكتبات الذكاء الاصطناعي، ودمج صفحات HTML ومجلد `static` بالكامل داخل `dist\mada-rag-server.exe` عبر PyInstaller.*

```text
mada-rag/
├── mada-rag-server.exe       ← الملف التنفيذي الرئيسي المدمج بالكامل
├── run-mada-rag.bat          ← مشغّل التطبيق بضغطة زر مع ضبط المسارات

├── bg_config.json            ← إعدادات المنبثقة والاختصارات المحفوظة
├── README.txt                ← إرشادات الاستخدام المرفقة مع النسخة
└── portable/
    ├── llama/                ← محرك llama-server.exe ومكتبات CUDA/AVX الملحقة
    └── models/               ← المجلد المخصص لوضع ملفات النماذج (.gguf)
```

# مَدى — مساعد RAG المحلي
**mada-rag-assistant**

محرك دردشة توليدي بالعربية مع استرجاع إثرائي (RAG) يعمل **محلياً بالكامل** على جهازك — لا يحتاج إنترنت ولا رفع بيانات لأي خادم خارجي.

## ⚡ لماذا «مَدى»؟

- **خصوصية تامة**: النموذج يعمل على جهازك عبر `llama.cpp` — كل المحادثات والتوليد محلي، بلا أي اتصال خارجي.
- **تقاطٌ ذكي**: حدّد أي نص في أي برنامج واضغط الاختصار ليُولَّد رد فوري على التحديد، في نافذة منبثقة قرب مؤشرك.
- **عربي بالكامل RTL**: واجهة مشبعة بالعربية مع اتجاه يمين-إلى-يسار صحيح في كل التفاصيل.
- **مساعد تفاعلي**: شريط جانبي، مشروعات، محادثات، وضعان (عام/اقتصادي)، أرشيف محلي كامل.

---

## 🚀 التشغيل السريع

> تتطلب الواجهة **إدارة (Administrator)** لتسجيل الاختصارات العالمية وتفعيل الخلفية.

1. اضغط نقراً مزدوجاً على: **`start-admin.bat`**
2. انتظر رسالة «الخادم يعمل» ثم افتح المتصفح:
   - **الدردشة**: http://127.0.0.1:8787/chat
   - **المشروعات**: http://127.0.0.1:8787/projects
3. (اختياري) أنشئ اختصاراً على سطح المكتب يشير إلى `start-admin.bat`.

للتشغيل يدوياً بدون واجهة الإدارة:

```bash
python -X utf8 server.py
```

الخادم يستمع على `127.0.0.1:8787` — عقدة محلية فقط، غير مكشوفة للشبكة.

## ⌨️ الاختصارات

| الاختصار | الوظيفة |
|---|---|
| `Ctrl+Alt+Space` | **المنبثقة السريعة**: توليد رد على التحديد الحالي في أي برنامج |
| `Ctrl+Alt+R` | إعادة فتح آخر رد مولَّد فوراً دون انتظار نموذج الإدخال |

> 💡 كلا الاختصارين **قابلان للتخصيص** من صفحة الإعدادات، مع مسجِّل اختصارات تفاعلي (اضغط المفاتيح بدل الكتابة).

> ⚠️ **ملاحظة مهمة**: تجنّب استخدام `Space` وحده (أو مع `Ctrl`/`Alt` فقط) كمفتاح رئيسي للاختصار، لأنه يتعارض مع مفتاح تبديل اللغة العربية/الإنجليزية في ويندوز — وتظهر لك تحذيرات تلقائية في صفحة الإعدادات عند ذلك.

## 🛠️ بنية المشروع

```
mada-rag/
├── server.py              ← الخادم الرئيسي (Flask + توليد عبر llama.cpp)
├── background_agent.py    ← الوكيل الخلفي للالتقاط والمنبثقة السريعة
├── chat.html              ← واجهة الدردشة
├── index.html             ← الصفحة الرئيسية
├── model_config.json      ← إعدادات النموذج (المسار، السياق، الحرارة…)
├── bg_config.json         ← إعدادات الوكيل الخلفي والاختصارات
├── mada.db / chat.db      ← قواعد بيانات المحادثات والمشروعات
├── start-admin.bat        ← مشغّل التشغيل كمسؤول
└── static/
    ├── css/               ← التصميم (عربي RTL + النوافذ + الرسوم المتحركة)
    └── js/                ← منطق الواجهة (الدردشة، المشروعات، الملفات، الإعدادات…)
```

## ⚙️ إعدادات مهمة

| الملف | يُضبط فيه |
|---|---|
| `model_config.json` | مسار النموذج `.gguf`، حجم نافذة السياق، الحرارة، المنفذ |
| `bg_config.json` | تفعيل الوكيل الخلفي، الاختصارات، وضع الالتقاط، مدة العرض |
| `background_agent.py` | إعدادات النموذج الاحتياطية للالتقاط السريع |

يُحمَّل النموذج من قرصك المحلي (افتراضياً من مجلد `D:\jan\llamacpp\models\…`) — ضع أي ملف `GGUF` متوافق (Qwen / Jan / Llama) وقدّره فوراً من طريق `model_config.json` دون تعديل الكود.
